# MLW

  1. Para que MLW Funcione descarga el Codigo
  2. Ve a Releases descarga el Complemento
  3. Descomprime ambos archivos
  4. Pon el Complemento dentro de la Raiz
  5. Y fuera del SRC
  6. Luego ve a la Raiz
  7. Click Derecho Abrir Terminal
  8. Y en la Terminal pon : Code .
  9. El Punto va
  10. Luego de que VSC Abra ve a la terminal con Control + J
  11. Y Escribe : npm run dev
  12. Copia la ruta del Localhost y pegala en el Navegador
